# Bt Studio

Онлайн-студия для битов в духе FL Studio. Работает прямо в браузере, без установки и без библиотек: весь звук синтезируется через Web Audio API.

## Что умеет

- **Обучение** (кнопка наверху или <kbd>F2</kbd>) — пошаговые уроки прямо в студии: нужное место подсвечивается, шаг проверяется сам, есть кнопка «Сделай за меня». Три курса: «Как устроен Bt», «Джерк-бит» (808 на каждую долю, глайды, хэты 3+3+2, «стопы») и «Плаг и тёмный 808» (неровный 808, длинные глайды, триоли). Уроки основаны на разборе треков tewiq, madk1d, greyrock, soulrin и других: темп, тональность, ритм и громкость измерены по разделённым дорожкам.
- **Channel Rack** — степ-секвенсор на 16–128 шагов: клик ставит удар, протяжка рисует, правая кнопка стирает, колесо меняет громкость удара. Кнопка канала открывает настройки звука, номер слева выбирает дорожку микшера.
- **Piano Roll** — карандаш, выделение рамкой, ластик, привязка к сетке (включая триоли), штамп аккордов, подсветка лада, ноты других каналов, дорожка громкости, квантование, копирование и вставка, транспонирование стрелками.
- **Playlist** — сборка трека из паттернов: клип можно растянуть, и паттерн будет повторяться; дорожки можно глушить, а клик по линейке задаёт старт.
- **Микшер** — 16 дорожек и мастер, фейдеры, панорама, mute/solo, стерео-индикаторы, быстрый 3-полосный EQ и до 8 эффектов на дорожку.
- **Эффекты** — параметрический EQ, компрессор, реверб, дилей (синхронизирован с темпом, есть пинг-понг), дисторшн, фильтр с LFO, хорус, фейзер, Lo-Fi (биты, плавание, винил), сайдчейн-«помпа», стерео-ширина, лимитер.
- **Инструменты**
  - синтезатор: 2 осциллятора, FM, саб, шум, унисон до 8 голосов, фильтр с огибающей, LFO, pitch envelope, глайд, драйв; 21 пресет (supersaw, pluck, пэды, рис, acid, колокола, электропиано, струнные, plugg keys и т. д.);
  - 808: удар, глайд при перекрытии нот, дисторшн и щелчок;
  - драм-синт: бочки, снейры, клэпы, хэты (закрытый хэт глушит открытый), крэш, райд, томы, перкуссия, импакт, райзер и даунлифтер;
  - сэмплер для своих WAV/MP3: корневая нота, старт и конец, реверс, петля, режим «по длине ноты».
- **Запись с клавиатуры**: Z…M и Q…P играют как пианино, кнопка ● пишет ноты в паттерн. Есть метроном и свинг.
- **Шаблоны**: Trap, Джерк, Плаг, House, Lo-fi.
- **Сохранение**: undo/redo (Ctrl+Z / Ctrl+Y), автосохранение, «Мои проекты» (в облаке аккаунта Claude, если страница открыта как артефакт, иначе в браузере), файл проекта `.bt.json`.
- **Экспорт**: WAV 16/24 бит (рендер быстрее реального времени, с нормализацией) и MIDI.

## Запуск

Сборка одной командой, нужен только Node 18+:

```bash
node build.mjs          # собирает dist/index.html (один файл)
```

После этого открой `dist/index.html` в браузере или запусти любой статический сервер.

## Деплой (tlfpaas)

В репозитории есть `Dockerfile` (собирает страницу и отдаёт её через непривилегированный nginx на порту 8080) и `docker-compose.yml` с одним публичным сервисом `web` (`tlfpaas.route: "web"`). Каждый push в GitHub запускает деплой. Результат смотри на https://deploy.tlfedu.tech/my/projects.

Локальная проверка в Docker:

```bash
docker compose build && docker compose run --rm -p 8080:8080 web
```

## Устройство кода

Весь код лежит в `src/`, а `build.mjs` склеивает его в `dist/index.html` по порядку номеров:

| Файл | Что внутри |
|---|---|
| `01-util.js` | мелкие помощники, создание элементов, цвета |
| `02-defs.js` | параметры инструментов и эффектов, пресеты, лады, аккорды |
| `03-dsp.js` | синтез звука: голоса синта, 808, ударных, сэмплера; эффекты; WAV и ZIP |
| `04-engine.js` | микшер (граф Web Audio), транспорт и планировщик нот, рендер, MIDI |
| `05-project.js` | модель проекта, шаблоны, undo/redo, сохранение |
| `06-ui-core.js` | ручки, меню, диалоги, плавающие окна, клавиатура-пианино |
| `07-ui-top.js` … `14-ui-dialogs.js` | верхняя панель, браузер звуков, Channel Rack, Piano Roll, Playlist, микшер, окно инструмента, диалоги |
| `15-main.js` | раскладка, горячие клавиши, цикл отрисовки, запуск |
| `style.css`, `index.html` | стили и каркас страницы |
